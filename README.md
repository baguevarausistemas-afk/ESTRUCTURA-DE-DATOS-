# 📚 Estructura de Datos con Python

Este repositorio contiene la resolución de ejercicios, talleres y algoritmos prácticos sobre **Estructuras de Datos** desarrollados en Python.

---

## 📋 Contenido del Repositorio

- **Matriz de Notas y Asignaturas:** Algoritmos para cálculo de promedios por fila/columna, nota mayor y nota menor.
- **Algoritmos de Ordenamiento y Búsqueda:** Ejercicios prácticos de ordenamiento (Bubble Sort, etc.).
- **Lógica de Programación:** Uso de estructuras de control, bucles y manejo de excepciones en Python.

---

## 🛠️ Tecnologías y Herramientas

- **Lenguaje:** Python 3.x
- **Entorno de Desarrollo (IDE):** Visual Studio Code
- **Control de Versiones:** Git & GitHub
